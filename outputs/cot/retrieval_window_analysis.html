Summary

Retrieval relevance varies sharply by item. NoInterest surfaces a relevant term 100% of the time (a distinctive keyword), while Concentrating does so only 55% of the time — for Concentrating the model is often reasoning over windows that never name the symptom. Appetite additionally has the weakest retrieval scores (top-1 0.50).

The link to errors is real but not clean: the two items that are both thin-evidence and high far-off (Failure, Appetite) are exactly the worst items in the error analysis — but across all items the keyword-hit ↔ far-off correlation is only weak (r=0.00), because far-off also depends on label skew. Concentrating is the clearest confound: worst retrieval yet low far-off, because 57% of its labels are 0, so "predict 0" is usually right regardless of evidence (see the frac y=0 column).

Takeaway. For several items (notably Failure and Appetite) retrieval frequently returns windows that never mention the symptom — part of the model's difficulty is upstream of reasoning: the evidence (and often the interview itself) lacks the signal. The relationship to far-off errors is confounded by label base rates, so this is supporting evidence, not proof, for the evidence/label ceiling. The one upstream lever still untried is item-aware retrieval (querying with the symptom's own vocabulary) — most promising for the low-hit-rate items.
