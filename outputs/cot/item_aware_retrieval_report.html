Item-aware querying raises the mean keyword-hit rate by +0.17 over the bare-item BM25 baseline, with the biggest gains on the items the analysis flagged as evidence-starved (Concentrating, NoInterest, Appetite) — on Appetite and Concentrating it even exceeds the existing hybrid retrieval. But Failure and Moving stay low even after expansion, indicating those symptoms genuinely are not verbalised in the interviews — a true ceiling that retrieval cannot fix.

Read this honestly: because the query is expanded with the same symptom vocabulary used to measure hit-rate, this metric is partly circular and is expected to rise — it shows the retriever can surface symptom-mentioning windows when asked, not that downstream accuracy improves. The decisive test is a CoT run on this evidence (the dataset written to phq8_item_dataset_itemaware_w3.csv), evaluated on the same folds.
